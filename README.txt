HSK 3 · Lesson 3 — 这个小区挺好的
Откройте index.html в браузере или загрузите все файлы и папку images/ в корень GitHub Pages репозитория.
Не загружайте только index.html: фотографии находятся в images/.
Кнопки: 拼音 — показать пиньинь; 翻译 — перевод; 教 — ответы для учителя; 清空 — сброс.
Стрелки внизу или клавиши ← → переключают страницы.
В упражнениях выбор ответа кликом, слова перетаскиваются мышью или выбираются кликом, затем кликом по пустому полю.
Аудио 3-1 и 3-3 из учебника запускается преподавателем отдельно, аудиофайлы не включены.
Изображения объектов и диалогов взяты из предоставленных пользователем страниц учебника; часть иллюстраций нарисована в HTML.
